# 月度成长报告 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：跨平台数据复盘师 的使用者"]
  T["触发层：月度成长报告"]
  X["执行层：2 个步骤"]
  O["产出层：成长档案报告（可对外分享）"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 中腰部以上创作者（多平台运营、有复盘意识但无方法的人群）；员工定位：把割裂的各平台后台归一成一张看得懂、能指导下周选题的复盘报告 |
| 触发层 | 关键词 / 显式点名「月度成长报告」；触发方式：定时（每月 1 日） |
| 执行层 | 月度数据 → 成长档案报告（可对外分享） |
| 产出层 | 成长档案报告（可对外分享） |
